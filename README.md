# Dholera Investors Meet – Jaipur

Registration page for the Dholera Investors Meet, 11 October 2026, Rajasthan International Centre, Jaipur.
Hosted by Arch Point Consultants Pvt. Ltd. in association with Nestoria Group.

Static site: no build step.

- `index.html`: the page (Tally form embedded at the top)
- `logo.png`: Arch Point logo
- `vercel.json`: Vercel settings

## Deploy

1. Push this folder to a GitHub repository.
2. In Vercel: Add New > Project > import the repository.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty. Deploy.

## Change the form

The Tally form ID is in `index.html` (search for `tally.so/embed/`). Replace `LZQ5MJ` with a new form ID.
